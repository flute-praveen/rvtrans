## 🚀 Quick Start (3 Steps)

```bash
# 1. Install dependencies
npm install

# 2. Install Vite
npm install --save-dev @vitejs/plugin-react vite

# 3. Run development server
npm run dev
```

**That's it!** Website opens at `http://localhost:3000`

## 🔧 Customization Guide

### Change Colors
Edit the color classes in components:
- `orange-500` → your color
- `slate-900` → your background

### Update Content
Edit the relevant page in `src/pages/`:
- Text content in JSX
- Stats and numbers
- Contact information

### Add Images
1. Place images in `public/images/`
2. Reference as `/images/filename.jpg`
3. Replace placeholder sections

### Modify Sections
- Each page is self-contained
- Easy to add/remove sections
- Copy existing patterns

## 🐛 Troubleshooting

### Dependencies won't install?
```bash
rm -rf node_modules package-lock.json
npm install
```

### Port 3000 in use?
Vite will auto-use next port (3001, 3002...)

### Build errors?
```bash
npm run build -- --debug
```
