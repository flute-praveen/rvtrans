# RV Trans Logistics LLP - Official Website

A modern, professional website for RV Trans Logistics LLP, showcasing their vehicle transportation and relocation services across India.

## 🚀 Features

### Multiple Pages
- **Home** - Hero section with company overview and trust indicators
- **Services** - Detailed service offerings with process flow
- **About** - Company history, team, values, and achievements
- **Fleet** - Complete fleet details with 24+ vehicles
- **Gallery** - Visual showcase of operations
- **Contact** - Contact form and office locations

### Design Highlights
- ✨ Modern gradient design with orange accent colors
- 📱 Fully responsive mobile-first design
- 🎨 Professional animations and transitions
- 🎯 Optimized user experience
- 🔒 GST compliant information display

## 🛠️ Technology Stack

- **React 19** - Latest React framework
- **Tailwind CSS** - Utility-first CSS framework (via CDN)
- **Lucide React** - Beautiful icon library
- **Vite** - Next generation build tool

## 📦 Installation

1. **Install dependencies:**
```bash
npm install
```

2. **Install Vite (if not already installed):**
```bash
npm install --save-dev @vitejs/plugin-react vite
```

## 🚀 Running the Project

### Development Mode
```bash
npm run dev
```
The site will open at `http://localhost:3000`

### Build for Production
```bash
npm run build
```
Output will be in the `dist` folder

### Preview Production Build
```bash
npm run preview
```
